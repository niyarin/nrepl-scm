# nrepl-scm
Network REPL for Guile or Gauche.

## usage
```sh
./nrepl-scm guile
```
```sh
./nrepl-scm gauche
```

## install
```sh
chmod +x ./install.sh
PREFIX=$HOME/.local ./install.sh
```


## test
```sh
guile -L ./  test/nrepl/bencode.scm
```
